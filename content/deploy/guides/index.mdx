# Faable Deploy guides

Every guide starts from a GitHub repository and ends at a live URL with free SSL. New to Faable Deploy? Do [Get Started](/deploy/get-started) first — it takes a few minutes.

## Web apps and APIs

| Guide                                           | What it covers                                                                   |
| ----------------------------------------------- | -------------------------------------------------------------------------------- |
| [Next.js](/deploy/guides/guide-next)            | Zero-config build and start, automatic standalone output, environment variables. |
| [Node.js Express](/deploy/guides/guide-express) | The `$PORT` contract, zero-config builds and environment variables.              |
| [Vite](/deploy/guides/guide-vite)               | React, Vue, Svelte, Solid or Preact as a static build, with SPA routing.         |
| [Astro](/deploy/guides/guide-astro)             | Static builds, the SSR adapter path and `PUBLIC_` variables.                     |
| [Django](/deploy/guides/guide-django)           | gunicorn start command, static files with WhiteNoise, migrations.                |
| [FastAPI](/deploy/guides/guide-fastapi)         | uvicorn start command and async workers.                                         |
| [Flask](/deploy/guides/guide-flask)             | gunicorn start command and a complete JSON API example.                          |
| [PHP & Laravel](/deploy/guides/guide-php)       | Apache with mod_php and `.htaccess`, composer, a full Laravel walkthrough.       |
