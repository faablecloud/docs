# Faable Deploy

Faable Deploy builds and runs your app straight from a Git repository: push your code and Faable detects the framework, builds an image, and serves it at `<app>.faable.link` with free SSL — no Dockerfile, pipeline or server to manage. Full backends, not just static sites: long-lived Node.js, Python and PHP processes, hosted in Europe.
